# Lernlauscher

Unterricht aufnehmen, zusammenfassen, verstehen und lernen – als Web-App fürs iPhone.

- Läuft komplett im Browser, alle Daten bleiben auf dem Gerät.
- KI: Google Gemini (kostenloser Schlüssel aus https://aistudio.google.com/apikey, wird in der App eingetragen).
- Installieren: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Lokal testen: `node tools/serve.mjs` → http://localhost:5178

Hinweis: Unterricht nur mit Erlaubnis der Lehrkraft aufnehmen (§ 201 StGB).
